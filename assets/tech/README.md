# Technology icons

The profile displays these icons at 24 x 24 pixels. PNG files are rendered at 72 x 72 pixels from the SVG sources in this directory.

- Python, C++, PyTorch, OpenCV, Git, ROS, and FastAPI icons come from [Devicon](https://github.com/devicons/devicon) under the accompanying [MIT license](LICENSE.txt).
- The ROS 2 entry uses the ROS mark. The ROS and FastAPI sources added in this update are pinned to Devicon commit `32fe1d3b3f36ad11f90ab94f7db59738139c2bf6`. The ROS fill is adapted to `#4C8ED9` for visibility on both GitHub themes; its geometry is unchanged.
- The YOLO entry uses the Ultralytics icon from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/icons/ultralytics.svg), under [CC0](LICENSE-simple-icons.md). Its fill is adapted to `#8B5CF6` for theme contrast; its geometry is unchanged.
